
# Trabalho Final 

Trabalho desenvolvido no final do semestre da disciplina de Programação Orientada a Objetos.

## Enunciado do Trabalho

O trabalho tinha como objetivo desenvolver o jogo Mastermind, também conhecido pelo nome Mini Senha.

Para o desenvolvimento, era necessário o desenvolvimento em Java utilizando os conceitos de programação orientada a objetos vistos em aula, assim como sua interface também em Java utilizando JavaSwing.
